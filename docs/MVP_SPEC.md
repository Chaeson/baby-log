# TwinLog MVP Spec

## Capability

쌍둥이 부모가 모바일에서 첫째와 둘째의 오늘 상태를 한 화면에서 비교하고, 빠른 터치 또는 짧은 음성으로 수유·기저귀·수면 기록을 남긴다. 기록은 가족 구성원에게 안전하게 공유되며 날짜별로 다시 확인할 수 있다.

## MVP Success Criteria

- 부모가 10초 안에 첫째 또는 둘째의 수유·소변·대변·수면 시작/종료를 기록할 수 있다.
- 앱을 열면 두 아이의 마지막 기록과 오늘 합계를 한 화면에서 비교할 수 있다.
- 저장한 기록은 새로고침·다른 기기·다른 가족 구성원에게도 유지된다.
- 기본 음성 명령은 확인 후 정확히 기록으로 저장된다.

## Included Scope

### Account and family

- 이메일 또는 소셜 로그인으로 부모 계정을 식별한다.
- 한 사용자는 하나의 가족을 생성하고 첫째·둘째 이름을 등록한다.
- 24시간 유효한 일회성 초대 코드로 두 번째 보호자를 추가한다.
- 모든 가족 조회·기록 API는 로그인 사용자와 가족 관계를 확인한다.

### Today

- 첫째와 둘째를 탭 전환 없이 동시에 표시한다.
- 아이별 마지막 분유(시간/용량), 수면 상태와 경과 시간, 마지막 소변·대변, 오늘 분유량·수면시간을 표시한다.
- 분유·소변·대변·수면 시작/종료 빠른 기록을 제공한다.
- 저장이 성공하면 Dashboard, 현재 상태, 합계를 즉시 갱신한다.

### Records

- 오늘·어제·직접 날짜 선택의 Timeline을 제공한다.
- 전체/아이/이벤트 유형 필터를 제공한다.
- MVP에서는 기록 조회와 추가만 제공한다. 잘못된 기록의 수정·삭제는 고객 지원 또는 다음 단계로 둔다.

### Voice record

- 브라우저 마이크 녹음과 한국어 STT를 제공한다.
- 아래의 정형 명령을 해석한다.
  - `첫째 분유 120`, `둘째 응가`, `둘 다 소변`
  - `첫째 잠들었어`, `둘째 일어났어`
  - `첫째 120 먹고 둘째 90 먹었어`
- 해석 결과를 아이별 이벤트 카드로 보여 주고 사용자가 **기록하기** 또는 **수정**을 선택한다.
- 해석하지 못한 문장은 저장하지 않고 재녹음/직접 기록을 안내한다.

### Basic insights

- 최근 7일 수유량·수면시간의 아이별 합계와 비교만 제공한다.
- 의료 판단, 위험도, 진단성 알림은 제공하지 않는다.

## Implementation Contract

### Data and API

- Family와 Child는 로그인된 사용자와 연결된다.
- BabyEvent에는 작성자, 생성 시각, 이벤트 시각, 아이 ID, 타입, 선택적 용량을 유지한다.
- 음성 해석은 `transcription -> parse candidates -> user confirmation -> event create` 순서이며, STT가 직접 이벤트를 만들지 않는다.
- 이벤트 생성은 클라이언트가 생성한 idempotency key를 받아 중복 탭/재전송을 막는다.

### Security and operations

- OpenAI 키, DB 비밀번호는 브라우저·Git에 저장하지 않고 ECS Secrets Manager 주입만 사용한다.
- 공개 배포 전 인증, 가족 권한 검사, HTTPS, CORS origin 제한, 요청 제한을 적용한다.
- MVP 운영 DB는 Aurora PostgreSQL이고 Flyway migration으로만 스키마를 변경한다.
- 운영 배포 전 실제 PostgreSQL에서 등록·기록·조회·재시작 후 데이터 유지 흐름을 검증한다.

## Explicit Non-goals

- AI 대화(첫째 AI·둘째 AI·쌍둥이 AI)와 Context Builder
- 자유 형식 육아 상담 및 의료 조언
- 고급 인사이트, 장기 리포트, 푸시 알림
- 기록 수정/삭제 UI, 대량 기록 페이지네이션
- iOS 네이티브 앱, Siri, 외부 서비스 연동
- 다태아 3명 이상에 특화된 화면 최적화

## Delivery Order

1. 실 PostgreSQL/Aurora 연결 및 로그인·가족 권한
2. Dashboard·빠른 기록·날짜별 기록을 인증된 실데이터로 운영 검증
3. 음성 명령 parsing, 확인 UX, 멱등 저장
4. 최소 7일 비교 인사이트, 실제 iPhone/Android 브라우저 검증
5. ECS 배포, 예산 알림, 모니터링 및 파일럿 운영

## MVP Decisions

- 로그인: Cognito Hosted UI 이메일/비밀번호, Authorization Code + PKCE.
- 초대: 소유자가 발급한 일회성 코드. 이메일 발송 기능은 제외.
- 기록 수정/삭제: 이번 MVP 제외. 출시 전 운영 지원 절차 필요.
- 음성 해석: 규칙 기반 정형 명령부터 제공. 모호하거나 지원하지 않는 문장은 저장하지 않음.
- 실제 AWS 배포: 예산·IAM/SSO·API 도메인·인증서 확인 후 진행.
